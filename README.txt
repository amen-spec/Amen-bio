TOKURA — SILVER NOIR BIO

Files
- index.html: single-page profile structure and links
- style.css: responsive black-and-silver design and animated silver-lined buttons
- script.js: share button, profile photo preview, and gallery preview
- .nojekyll: helps GitHub Pages serve files as-is

Preview locally
Open index.html in a modern browser. Some browser sharing features work only on HTTPS or supported browsers.

Personalize links
In index.html, replace the placeholder Instagram, TikTok, X and email destinations with your real profile/contact links.

Photo note
The photo picker and gallery are browser previews only. They do not upload images to GitHub or save them for other visitors. To show gallery photos to everyone on the live site, add image files to the repository (for example in an images/ folder) and reference them in index.html, or implement an upload service.

Deploy on GitHub Pages
1. Sign in to GitHub and create a new repository (for example: tokura-bio).
2. Upload index.html, style.css, script.js and .nojekyll to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and / (root), then Save.
5. Wait for the published URL shown in the Pages settings.

Privacy
This version is intended to be public. Anyone with the published URL can visit it. Do not publish sensitive information. GitHub Pages is static hosting and does not provide password protection for this page by itself.
